Хакатон X5: проектирование системы игровой лояльности. Персональный игровой слой поверх X5 Клуба (рабочее название — «Домовой»).

## Что делаем

Always-on игровой слой в приложении «Пятёрочка»/«Перекрёсток»: цифровой персонаж, которого кормят реальные чеки, еженедельный персональный челлендж экономии от LLM-агента, анонимный рейтинг «Лига дома» и реферальная программа «Позови соседа».

Три механики из кейса:

1. **Личный прогресс** — аватар «Домовой» и персональный челлендж экономии.
2. **Рейтинг экономии** — лиги по 30 человек с похожей активностью, привязка к любимому магазину, без ФИО и адресов.
3. **Реферальная программа** — награда только за реактивацию «спящих» и новых покупателей, выплата после второй покупки приглашённого.
