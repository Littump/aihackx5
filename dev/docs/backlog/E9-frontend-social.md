# E9 — Frontend: League, Referral

## FE-004 League
**Описание:** PRD §4 Screen 3: дивизион с названием, неделя, список 30 под псевдонимами с подсветкой «я», зоны цветом, «лучше, чем N %», карточка «Дом vs район», анимация изменения места после Simulate (сравнение `league_rank_before/after` из результата).
**AC:** тесты рендера, подсветки моего места, зоны; на экране нет никаких полей, кроме `pseudonym, level, score, rank`.

## FE-005 Referral
**Описание:** PRD §4 Screen 4: код и ссылка с кнопкой «Скопировать», QR (библиотека `qrcode.react`), правила списком, награды, приглашённые как «Сосед №N» со статусом и прогрессом «1 из 2 покупок», лимит «2 из 5 в этом месяце».
**AC:** тесты рендера и копирования; статусы `on_review`/`blocked` показываются нейтрально («на проверке»).
