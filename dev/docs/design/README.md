# Дизайн-система «Домовой»

Источник истины по визуалу — [mockup.html](mockup.html). Открывается в браузере как один файл, ничего не требует, кроме Tailwind CDN. Внутри: все экраны фреймами 390×844, PM view на 960px, библиотека компонентов, персонаж в пяти настроениях и трёх уровнях обжитости.

Макет проверен замерами: контраст всех текстовых пар, отсутствие обрезанного контента во фреймах, попадание hero-блока Home в первый экран. Перерисовка фронта идёт по эпику [E15](../backlog/E15-redesign.md).

Не путать с эпиком [E14 «ML-планировщик»](../backlog/E14-ml-planner.md) — это параллельная работа по бэкенду и LLM, файлов фронта не трогает.

## Правила, нарушение которых ломает макет

- Блок темы объявляется как `@theme static`. Tailwind v4 вырезает переменные, не встреченные ни в одном классе, а `fur-*` используются только внутри SVG персонажа — без `static` он рендерится чёрным.
- Цвета внутри SVG задаются классами `fill-fur-200`, `stroke-brand-700`, а не атрибутом `style`.
- Белый текст размером меньше 18px допустим только на `brand-700` и темнее. На `brand-600` белый даёт 4.06, на `brand-700` — 6.08.
- `brand-100` — цвет крупных подписей на зелёном, не основного текста: на `brand-600` он даёт 3.32.
- Текст на `accent-50` — только `accent-700`. `accent-600` на `accent-50` даёт 2.80.
- Белым по `accent-500` можно писать только от 18px и жирным.
- Скролл-контейнер экрана — `flex-1 min-h-0 overflow-y-auto`, прямые дочерние секции — `shrink-0`. Без этого длинные списки сжимаются и часть контента становится недостижимой.

## Что осознанно сделано иначе, чем в приложении X5

Одно главное действие на экран вместо шести конкурирующих блоков. Никаких рекламных баннеров. Цель недели — единственный цветной акцент на Home, всё остальное подчинено ей.
